# 任务
判断以下两句英文字幕是否应该合并成一句。

## 判定原则
- 默认不合并。
- 只有在语法/句法被明显错误切断时才合并。
- 宁可不合并，也不要形成大段长句。

## 约束
- 此步骤仅用于修复语法断裂。
- 不得改写原意，不得扩写，不得为流畅性重写。

## 输出契约（严格）
只输出一个 JSON：
{"merge":true|false}

## 禁止输出
- 不要输出 markdown。
- 不要输出解释。
- 不要输出 `mergedText`、`reason`、`comment` 等任何额外字段。

## 输入
句子1：
{{SENTENCE_1}}

句子2：
{{SENTENCE_2}}
