# ADR-0001: zimu 的 CLI 产品方向

- 状态：已接受
- 日期：2026-10-23

## 背景

项目希望成为轻量、实用的字幕翻译与播放工具。[Mole](https://github.com/tw93/Mole) 展示了短命令如何解决常见的实际问题。当前仓库已有 CLI 流水线和 Web 工作台，但产品入口、任务恢复和字幕操作主要围绕 Web 工作台组织。

## 决策

面向用户的产品名定为 **zimu**，同时提供 `zimu` 和 `zm` 两个启动命令。当前专注 CLI；macOS 是首要打磨平台。普通短命令支持直接操作和脚本使用，无参数启动进入引导式终端界面，界面底部持续显示可用按键。命令的帮助、输出、错误和退出码参考[命令行界面设计指南](https://clig.onev.dev/#philosophy)。

`translate` 接受在线视频 URL 或本地视频；URL 输入自动下载。`download` 提供单独下载功能。默认翻译范围是英文到中文。即使存在原文字幕，默认仍用 Whisper 从音频转录。`standard` 保留自动 LLM 校对；`meme` 保持当前关闭自动校对的设置。当前不提供人工逐句校对。

默认交付中文字幕 SRT，可按需生成双语 SRT；视频烧录是可选操作。本地视频的最终字幕同时保存在任务目录和原视频旁边。翻译完成后提示用户选择播放：优先使用已安装且能明确加载外置字幕的播放器；找不到时打开默认播放器，并提示用户手动加载字幕。播放器不作为必装依赖。

交互界面支持逐项加入多个任务。任务历史可用于查看状态和选择恢复，短命令也能指定任务恢复。进度只显示已知的阶段、已完成与总条目、耗时及队列位置，不显示猜测的百分比或预计完成时间。

## 影响

- 新开发聚焦 CLI；现有 Web 工作台保留可用，暂停新增 Web 功能。当前不规划 GUI 或 App。
- 安装方式优先减少步骤，允许使用系统已安装的 Python、FFmpeg 等工具；依赖检查应清楚、快速。
- 先更改面向用户的名称和命令。内部 .NET 项目名可分阶段迁移；GitHub 仓库是否更名以后另行决定。
- Whisper 完整转录与自动 LLM 校对会增加等待时间。保留这两项是明确的产品选择，应优化无意义的等待并如实呈现实际进度。
